# 🛡️ Enterprise Email AI Classifier

## Setup Instructions
1. Extract the folder.
2. Open terminal in this folder.
3. Install dependencies:
   `pip install -r requirements.txt`
4. Run the application:
   `python -m streamlit run app_ui.py`

## Features
- **AI Engine:** Multinomial Naive Bayes.
- **Hybrid Logic:** Combined Machine Learning + Keyword Safety Net.
- **Persistence:** Automatically saves and loads trained models.
- **Diagnostics:** Real-time confidence scoring.
